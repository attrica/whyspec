# ADR-0032: Retire the legacy export endpoint

**Status:** Accepted
**Date:** 2026-06-09

## Context

Should the legacy export endpoint stay online?

## Decision

Every remaining caller has migrated, so the endpoint carries only maintenance cost.

## Alternatives considered

1. Retire the legacy export endpoint
2. Keep the legacy export endpoint behind a deprecation header
