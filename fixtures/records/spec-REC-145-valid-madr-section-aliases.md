# Use Prettier for the code style

- Status: accepted
- Date: 2020-09-25

## Context and Problem Statement

We have to choose a formatter and the code style to enforce.

## Considered Options

- Prettier only
- ESLint only
- Prettier-ESLint with the Airbnb style

## Decision Outcome

Chosen option: Prettier-ESLint with the Airbnb style, because the more opinionated the style is,
the fewer debates there are.
